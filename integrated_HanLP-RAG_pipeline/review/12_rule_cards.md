# Error categories and rule cards (draft)

One card per category of the teacher's corrections, drafted from her notes and her corrections on the
practice stories. The feedback system uses a card to decide whether a flagged error belongs to the rule and
to explain it to the learner. Every example is one of her own corrections. Decisions go in
`12_rule_cards_review.csv` (see `12_rule_cards_instructions.md`).

## Grammar

### 的 in modifier phrases  ·  `modifier_de_structure`

*57 of her corrections.* Category definition: Use 的 only where a modifier needs it, and omit it in structures that do not take 的. A descriptive modifier before a noun normally needs the appropriate 的 structure.

**Rule.** Use 的 after a modifier when it describes a noun, especially a longer phrase such as 人类创造的文明 or 能吃的植物. Do not add 的 after quantity words or fixed modifiers where it is not needed, such as 很多人, 一些人, 今天清晨, 蓝色衣服, and 好主意.

**How an error is explained.** <wrong> → <correct>: <modifier> describes the noun <noun>, so use 的; or <modifier> does not need 的 here, so omit it.

**Her terms.** no的

**Her examples.**

- 我无话可说！[人类创造文明→人类创造的文明]到底从哪里由此而来啊 — 人类创造文明 → 人类创造的文明: 人类创造 describes the noun 文明, so use 的.  *(her note: the Subj. should be a noun “文明”, not a verb phrase “人类创造文明”)*
- [找植物能吃→找能吃的植物] — 找植物能吃 → 找能吃的植物: 能吃 describes the noun 植物, so use 的.
- 很多[-的]人吃了有毒的饭 — 很多的人 → 很多人: 很多 does not need 的 before 人 here, so omit it.  *(her note: no的)*
- 今天[-的]清晨 — 今天的清晨 → 今天清晨: 今天 does not need 的 before 清晨 here, so omit it.
- 他们吃[毒→有毒的]植物 — 毒植物 → 有毒的植物: 有毒 describes the noun 植物, so use 的.

**Not an error under this rule.** Do not flag 的 in modifiers that need it, such as 有毒的植物, 中国的植物, or 穿着蓝色衣服的人. Do not add 的 after short fixed modifiers such as 很多, 一些, 今天, 蓝色, or 好 in the examples shown.

### 在+Place / 在Place + V.  ·  `location_with_zai`

*50 of her corrections.* Category definition: Use 在 + Place for a location, and place the location correctly before the action when needed: 在Place + V. or 住在+Place.

**Rule.** Use 在+Place for a location: put the location before the action as 在Place + V., or use 住在+Place. Add 里/上 when needed to make the place clear.

**How an error is explained.** <wrong> → <correct>: <place> is the location, so use 在+Place before the action.

**Her terms.** 在+Place · 在Place住 · 住在+Place · 在Place + V. · 在Place V1.着V2

**Her examples.**

- 孟母觉得孩子[成长在什么地方→在什么地方成长]很重要 — 成长在什么地方 → 在什么地方成长: 什么地方 is the location, so use 在Place + V.  *(her note: 在Place + V.)*
- 孟子和他的妈妈住在离墓地很近[+的地方] — 住在离墓地很近 → 住在离墓地很近的地方: 住 takes 住在+Place, so the location needs 的地方.  *(her note: 住在+Place)*
- 小王[在马路→在马路上]骑自行车一看到别个人 — 在马路 → 在马路上: 马路上 is the place, so use 在+Place.  *(her note: 在+ place)*
- 一个戴围巾的男人[站着在树顶的梯子上→在树顶的梯子上站着]拿一些梨 — 站着在树顶的梯子上 → 在树顶的梯子上站着: put the location before the action: 在Place V1.着V2.  *(her note: 在Place V1.着V2)*

**Not an error under this rule.** Do not add 上 after every place word: 农村 is already a place, so use 在农村住, not 在农村上住.

### V. + Obj. structure  ·  `verb_object_valency`

*41 of her corrections.* Category definition: Use each verb with the object and complement structure it allows; do not give a verb an extra object or omit a required one.

**Rule.** Use the verb structure that the verb allows: give it the needed object, and do not add an extra object after a V.+Obj. compound or complement. For example, 跑遍 + place, while 掉 cannot take an object by itself.

**How an error is explained.** <wrong> → <correct>: <verb/verb phrase> must take <the allowed object or complement structure>; <brief reason, such as “it is a V.+Obj. compound” or “the action is durative, so use 着durative”>.

**Her terms.** 着durative · 跑遍 + place · 管事V.+Obj. compound · 掉 + directional + place · resultative complement

**Her examples.**

- 他[拿说→拿着花说] — 拿说 → 拿着花说: holding the flower is durative, so use 着durative and put 花 after 拿着.  *(her note: 着durative)*
- [拿起骑车→扶起自行车] — 拿起骑车 → 扶起自行车: 骑车 is a verb phrase and cannot be the object here; use 自行车 as the object of 扶起.  *(her note: “骑车” is a verb phrase, cannot be the Obj. of “扶起”，“拿起” is usually used for smaller items.)*
- 他跑遍[+大山小山]尝尝各种各样的植物 — 跑遍 → 跑遍大山小山: 跑遍 needs a place after it.  *(her note: 跑遍 + place)*
- 孟母一直管[事儿，儿子的教养→儿子的教育] — 管事儿，儿子的教养 → 管儿子的教育: 管事 is a V.+Obj. compound, so it cannot be followed by another object.  *(her note: 管事V.+Obj. compound, not followed by another Obj.)*
- 他怎么能随便马虎得⟦掉我家庭⟧呢？一点都不合理 — 掉我家庭 is not possible: 掉 itself cannot take an object; use 掉 + directional + place, or use 掉 as a resultative complement after another main action verb.  *(her note: 摘掉我的家人：掉itself cannot be followed by an Obj., Subj. 掉 + directional + place, but掉can be resultative complement following another main action verb)*

**Not an error under this rule.** Do not flag 掉 when it is a resultative complement after another main action verb. 掉 can also be used in the structure 掉 + directional + place.

### V. + directional complement + Place + 来/去  ·  `directional_complements`

*31 of her corrections.* Category definition: Use directional complements in the correct order, for example 走到place来/去 and V. + directional complement + Place + 来/去. Do not use forms such as 走去 or 走来Place.

**Rule.** Use V. + directional complement + Place + 来/去: put the place after the directional complement and before 来/去. For walking to a place, use 走到place来/去, not 走去 or 走来Place.

**How an error is explained.** <wrong> → <correct>: put the place after the directional complement; use V. + directional complement + Place + 来/去 (or 走到place来/去).

**Her terms.** V. + directional complement + Place + 来/去 · 走到place来/去 · 走去/来Place · 拿起来 · 拿上去

**Her examples.**

- [爬下来梯子→爬下梯子来] — 爬下来梯子 → 爬下梯子来: put 梯子 after 下 and before 来: V. + directional complement + Place + 来/去.  *(her note: V. + directional complement + Place + 来/去)*
- 张先生[爬上去梯子→爬上梯子去] — 爬上去梯子 → 爬上梯子去: put 梯子 after 上 and before 去: V. + directional complement + Place + 来/去.  *(her note: V. + directional complement + Place + 来/去)*
- 孩子一直[走去张先生的树→走到张先生的树下] — 走去张先生的树 → 走到张先生的树下: for walking to a place, use 走到place, not 走去place.  *(her note: 走到place来/去，cannot say “走去/来Place”)*
- 马先生跟他的驴⟦走去筐的后边来⟧ — 走去筐的后边来: use 走到place来/去; do not say 走去 or 来Place.  *(her note: 走到place来/去，cannot say “走去/来Place”)*
- 他把灵芝[带回走了→带回家了] — 带回走了 → 带回家了: do not use both 回 and 走 together.  *(her note: but not both回and走)*

**Not an error under this rule.** Do not treat 拿起来 and 拿上去 as interchangeable word-order forms: 拿起来 means “pick up,” while 拿上去 means “bring it up.”

### 是……吗 / repeated Wh-Q  ·  `question_patterns`

*28 of her corrections.* Category definition: Form questions with the appropriate Chinese question pattern, such as 能不能吃, 知不知道, or the repeated Wh-Q pattern for “wh-ever…”.

**Rule.** Use 是……吗, V不V, or a Wh-question for an indirect question, not 如果. For “wh-ever…, will do that…”, repeat the Wh-word: 哪一筐……就……哪一筐.

**How an error is explained.** <wrong> → <correct>: this asks <whether/what/where>, so use <question pattern>, not 如果.

**Her terms.** repeated Wh-Q

**Her examples.**

- 看看[如果→是]毒还是药 — 如果 → 是: “see if” asks whether it is poison or medicine, so use 是……还是……, not 如果.  *(her note: the “if” in “see if + clause” is not 如果)*
- 不知道[如果有毒→有没有毒] — 如果有毒 → 有没有毒: “not know if” asks whether it is poisonous, so use a V不V question, not 如果.  *(her note: the “if” in “not know if + clause” is not 如果)*
- 我无话可说！人类创造文明到底⟦从哪里由此而来⟧啊 — 从哪里由此而来 → 从何而来: this asks where it comes from, so use a “where” question; 由此而来 means “come from this”.  *(her note: 到底从何而来：由此而来 means “come from this”, but here should be a question “come from where”.)*
- 男孩一看哪一筐有更多梨子就往自己的自行车上放[梨子的筐→哪一筐] — 梨子的筐 → 哪一筐: for “whichever basket has more pears, put that basket...”, repeat 哪一筐 in the result clause.  *(her note: the structure “repeated Wh-Q” expressing “wh-ever…, will do that…”.)*

### Num. + MW. + N., no 的  ·  `numeral_measure_word_order`

*19 of her corrections.* Category definition: With a number and measure word, use Num. + MW. + noun directly; normally do not add 的. Use V. + Num. + MW. + Obj. in the normal object order.

**Rule.** With a number and measure word, use Num. + MW. + noun directly, with no 的. For actions, use V. + Num. + MW. + Obj.; for a completed action, use 了completed, V. + Num. + MW. + Obj.

**How an error is explained.** <wrong> → <correct>: use <formula>; do not put 的 between the measure word and the noun / put the verb before the number phrase. <Action> is finished, so it takes 了 (了completed).

**Her terms.** V. + Num. + MW. + Obj. · 了completed · num. + MW. + noun, no的 · 再V. + Num. + MW. + N. · 才V. + Num.

**Her examples.**

- 所以他偷走[一筐的梨→一筐梨] — 一筐的梨 → 一筐梨: use Num. + MW. + noun directly; do not use 的.  *(her note: num. + MW. + noun, no的)*
- 他们[搬了家两次→搬了两次家] — 搬了家两次 → 搬了两次家: use V. + Num. + MW. + Obj.  *(her note: V. + Num. + MW. + Obj.)*
- 所以她[搬家二次→搬了两次家] — 搬家二次 → 搬了两次家: the action is finished, so use 了completed, V. + Num. + MW. + Obj.  *(her note: 了completed, V. + Num. + MW. + Obj.)*
- 我们要[搬家再一次→再搬一次家] — 搬家再一次 → 再搬一次家: use 再V. + Num. + MW. + N.  *(her note: 再V. + Num. + MW. + N.)*
- 可是[搬才三次→才搬了三次]就找到好的地方 — 搬才三次 → 才搬了三次: use 才V. + Num.; the action is finished, so it takes 了completed.  *(her note: 才V. + Num., 了completed)*

**Not an error under this rule.** Do not use 们 or 些 with a number: use 三个男孩, not 三个男孩子们, and 那三个男孩, not 那些三个男孩.

### resultative complement  ·  `resultative_complements`

*18 of her corrections.* Category definition: Use a resultative complement when the action has reached its result, for example 吃到, 找到, 撞到, 把Obj. V. Resultative complement.

**Rule.** Use a resultative complement when the action reaches its result: 吃到, 写下, 撞到+Obj., or 把Obj. V. Resultative complement.

**How an error is explained.** <wrong> → <correct>: the action reaches a result, so use <resultative complement>.

**Her terms.** 吃到result · 写下 · 撞到+Obj. · 把Obj. V. Resultative complement

**Her examples.**

- 然后写[+下了]他学了什么 — 写 → 写下了: the writing is completed, so use 写下.
- 一下子[撞了一个大石→撞到了一个大石头] — 撞了一个大石 → 撞到了一个大石头: the action reaches the rock, so use 撞到+Obj.  *(her note: add “又” to make it smooth, 撞到+Obj.)*
- 他用他的围巾[擦，把梨干净→把梨擦干净] — 擦，把梨干净 → 把梨擦干净: the pear becomes clean, so use 把Obj. V. Resultative complement.  *(her note: 把Obj. V. Resultative complement)*
- 特别是他[吃毒→吃到有毒的植物]的时候 — 吃毒 → 吃到有毒的植物: he comes across and eats a poisonous plant, so use 吃到.
- [一下子就撞自行车→自行车一下子就撞到石头了] — 一下子就撞自行车 → 自行车一下子就撞到石头了: 撞自行车 means to hit the bike; here the bike hits the rock, so use 自行车撞到石头.  *(her note: “撞自行车” means to hit the bike, in fact, it is: the bike hit the rock.)*

**Not an error under this rule.** Do not use 撞+Obj. when the meaning is that the object hits something else: 撞自行车 means to hit the bike.

### 想 + V.; 叫/让 + V.  ·  `modal_and_control_verb_complements`

*14 of her corrections.* Category definition: 想 must be followed by a verb phrase, not a noun. Control and modal-like verbs such as 叫/让 take a following action and do not take 了 in this use.

**Rule.** 想 must be followed by a verb phrase, not a noun; use 想让 + person + V. when you mean “want someone to do something.” 叫/让 + V. expresses an action someone is told or made to do, so do not add 了.

**How an error is explained.** <wrong> → <correct>: 想 needs a following action (想 + V.); use 想让 + <person> + <V.> if the person is meant to do the action.

**Her terms.** 想 + V. · 叫/让 is a modal verb · no了

**Her examples.**

- 孟母一直想[+让]她的孩子受到良好的教育 — 孟母一直想她的孩子受到良好的教育 → 孟母一直想让她的孩子受到良好的教育: 想 needs a following action, so use 想让 + person + V.  *(her note: 想 + V., cannot be followed by N.)*
- 孟母[想儿子→想让儿子]开始打工可能减轻她的负担 — 孟母想儿子开始打工可能减轻她的负担 → 孟母想让儿子开始打工可能减轻她的负担: 想 needs a following action, so use 想让 + person + V.  *(her note: 想 + V., cannot be followed by N.)*
- 他的妈妈[不想跟他的朋友去墓地→不想让他跟朋友去墓地] — 不想跟他的朋友去墓地 → 不想让他跟朋友去墓地: use 想让 + person + V.; otherwise, it means his mother did not want to go to the graveyard with his friend.  *(her note: otherwise it means his mother didn’t want to go with his friend to the graveyard.)*
- 孟子的妈妈叫[-了]孟子搬家 — 孟子的妈妈叫了孟子搬家 → 孟子的妈妈叫孟子搬家: 叫/让 is a modal verb here, so it takes no 了.  *(her note: 叫/让 is a modal verb, no了)*

**Not an error under this rule.** Do not flag 想 when it is followed by a verb phrase, such as 想尝什么植物. Do not add 了 to 叫/让 when it is followed by the action someone is told or made to do.

### Adj. can be predicate; usually Adj. takes 很  ·  `adjective_predicate_degree`

*12 of her corrections.* Category definition: An adjective can be the predicate without 是. Usually use 很 before an adjective when giving a plain description, unless another degree pattern is intended.

**Rule.** An Adj. can be the predicate without 是. Usually an Adj. takes 很 for a plain description; 是Adj.的 is used to emphasize.

**How an error is explained.** <wrong> → <correct>: <adjective> is a plain description, so use it as the predicate without 是 and usually add 很.

**Her terms.** Adj. can be predicate · usually Adj. takes 很 · 是Adj.的 is to emphasize

**Her examples.**

- 你应该特别[-是]小心 — 你应该特别是小心 → 你应该特别小心: 小心 is an Adj. predicate, so it does not take 是.  *(her note: Adj. can be predicate)*
- 第二个房子离购物中心[+很]近 — 第二个房子离购物中心近 → 第二个房子离购物中心很近: 近 is a plain description, so it usually takes 很.  *(her note: usually Adj. takes 很)*
- 孟母看出来孟子老是[+很]难过 — 孟母看出来孟子老是难过 → 孟母看出来孟子老是很难过: 难过 is a plain description, so it usually takes 很.  *(her note: usually Adj. takes 很)*
- 孟子[是淘气的孩子→很淘气] — 孟子是淘气的孩子 → 孟子很淘气: 淘气 can be the predicate; use 很淘气 rather than 是淘气的孩子.
- [有高的学历→学历很高]和厉害的主修 — 有高的学历 → 学历很高: use a short sentence with the Adj. predicate, 学历很高.  *(her note: instead of using “有……” structure, it is better to use short sentences: 学历很高)*

**Not an error under this rule.** Do not flag 是Adj.的 when the writer intends emphasis. Do not require 很 when another degree pattern, such as 特别, is used.

### 量词选择  ·  `measure_word_choice`

*11 of her corrections.* Category definition: Use the appropriate measure word for the noun, including polite 位 and noun-specific classifiers such as 棵.

**Rule.** Use the appropriate measure word before the noun: 这/那 + Measure word + noun. Use noun-specific measure words such as 棵 for trees, and 位 is a polite MW.

**How an error is explained.** <wrong> → <correct>: use <measure word> with <noun>; <brief reason, such as “位” is polite or 棵 is for trees>.

**Her terms.** 这/那 + Measure word + noun · 本+N. · 位 · MW

**Her examples.**

- 这[+个]奇怪的男孩一看到她 — 这奇怪的男孩 → 这个奇怪的男孩: 这/那 + Measure word + noun.  *(her note: 这/那 + Measure word + noun.)*
- 他这个没有礼貌的人每天爬上⟦本树⟧ — 本树 → 这棵树: use 棵 for a tree; 本+N. is usually formal advertisement/news language and can indicate ownership.  *(her note: 本+N. is usually used in formal advertisement/news, also it indicates the author owns the tree, which is not the fact: the author is a pear, who does not own the whole pear tree. 爬上这棵树。)*
- 有[一位小孩子叫孟子→一个叫孟子的小孩子] — 一位小孩子 → 一个叫孟子的小孩子: 位 is a polite MW.  *(her note: “位” is a polite MW.)*
- 一个农人爬着[一个树→一棵树] — 一个树 → 一棵树: use 棵 for a tree.

**Not an error under this rule.** Do not use 位 for a child in this context; 位 is a polite MW. 本+N. is usually used in formal advertisement/news and may indicate that the author owns the noun.

### miss a Subj.  ·  `missing_or_unclear_subject`

*11 of her corrections.* Category definition: State the subject when it is required for grammatical clarity, especially after an inserted narrator comment or when the previous subject cannot continue.

**Rule.** State the Subj. when leaving it out would make it unclear who does the action. Restate the Subj. after a different Subj. or an inserted “narrator comment” before returning to the main story.

**How an error is explained.** <wrong> → <correct>: Add <Subj.> because otherwise it is unclear who <action>; the previous <Subj./narrator comment> cannot continue here.

**Her terms.** Subj. · narrator comment

**Her examples.**

- [+他]就生病了 — 就生病了 → 他就生病了: Add 他 because otherwise it is ambiguous who gets sick.  *(her note: otherwise it is ambiguous who gets sick)*
- [+孟子]练习写文字 — 练习写文字 → 孟子练习写文字: Add 孟子; this sentence misses a Subj.  *(her note: miss a Subj.)*
- [+他们过来]用心得来帮忙整理梨子 — 用心得来帮忙整理梨子 → 他们过来用心得来帮忙整理梨子: Add 他们 because the preceding Subj. is 我们.  *(her note: since the preceding phrase has “我们”, the Subj. 他们 should be stated)*
- 我怎么能还要发火呢？但[+我]只能思考几分钟 — 但只能思考几分钟 → 但我只能思考几分钟: Add 我 because the preceding 我怎么能… is an inserted narrator comment, so the Subj. must be restated when returning to the story.
- 然后突然一口气吃掉了我家长！他到底以为自己是谁啊？难道以为自己是上帝吗？我生气极了！下午[就→他还]继续爬上树 — 下午就继续爬上树 → 下午他还继续爬上树: Add 他, or readers will understand the Subj. as 我; 还 gives a surprising, angry tone.

**Not an error under this rule.** Do not flag an omitted subject when the previous subject can clearly continue. A subject needs to be restated when the previous subject cannot continue or would cause ambiguity.

### 把 / 被  ·  `ba_bei_constructions`

*9 of her corrections.* Category definition: Use 把 for an initiated disposal action, usually with a result or completion; use 被 for passive voice. Do not use 把 when the subject did not cause the event.

**Rule.** Use 把 for an initiated action that disposes of an object: 把Obj. V. Resultative complement, usually ending with 了. Use 被 for passive voice (“be done”), not for an active or self-happening event.

**How an error is explained.** <wrong> → <correct>: <subject> <does/does not initiate> the action. Use <把Obj. V. Resultative complement + 了 / 被 / no 把> because <object> is <disposed of / passively affected / doing the action by itself>.

**Her terms.** initiated actions (“disposal”) · 把Obj. V. Resultative complement · passive voice “be done”

**Her examples.**

- 把帽子[弄掉→弄掉了] — 把帽子弄掉 → 把帽子弄掉了: this is a completed 把 action, so it usually ends with 了.  *(her note: “把”usually ends with了)*
- ⟦他把梨从筐里倒出去⟧ — 他把梨从筐里倒出去: do not use 把 because he did not initiate throwing the pears; the pears fell themselves, so use 倒下去/倒下来.  *(her note: “把“ is used for initiated actions (“disposal”), here it is not he who threw those pears, but the pears fell themselves. 倒 means “pour” if it is an initiated action, and means “fall” if it is not an initiated action, and followed by 下去/下来。)*
- [被→]筐里的梨子坐在地上了 — 被筐里的梨子坐在地上了 → 筐里的梨子坐在地上了: 被 means passive voice, “be done,” so do not use it here.  *(her note: 被 means passive voice “be done”)*
