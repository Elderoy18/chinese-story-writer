## mengmu_samples#4

### Scene 1

> 古代的时候，孟子和孟母住了在靠墓地的家。孩子才五岁就每天在墓地祭拜了。在那个城市，孟母从早到晚都找工作，可是找不到，害得孟母没有钱。难怪她跟孩子搬家，原来买不了房。他们搬了到别一个城市找工作。

**Grammar**
- 古代的时候 → 在古代: Use 在古代 for this time setting. Put 在 before the time/place phrase.
- 孟子和孟母住了在靠墓地的家 → 孟子和孟母住在靠墓地的家: 住在 describes a state here, so do not put 了 before 在. Use 住在+Place.
- (suggestion) …在靠墓地的家 → …在靠墓地的家里: It would be more natural to add 里 after 家, making the location clearer: 家里.
- …天在墓地祭拜了 → …天在墓地祭拜: 每天 shows a habitual action, so sentence-final 了 is not needed here.
- (suggestion) …母从早到晚都找工作 → …母从早到晚都在找工作: It would be more natural to use 在 for an action continuing from morning to night: 从早到晚都在找工作.
- 他们搬了到别一个城市… → 他们搬到了到别一个城市…: With 搬到, the directional complement 到 comes before 了. Use 搬到了+Place.
- (suggestion) 他们搬了到别一个城市找… → 他们搬了别一个城市找…: It would be more natural to use 搬到了+Place rather than adding a separate 到 after 搬了.

**Vocabulary**
- …和孟母住了在靠墓地的家 → …和孟母住了在靠近墓地的家: Use 靠近 to mean “near” a place. 靠近墓地 means “near the cemetery.”
- 他们搬了到别一个城市找工… → 他们搬了到另一个城市找工…: Use 另一个 for “another one.” 别一个 is not the standard expression here.

**Coherence: reference**
- ⟦孟子⟧和孟母住了在…: 孟子 appears for the first time here, so please introduce him briefly, not only with his name.
- 孟子和⟦孟母⟧住了在靠墓地…: 孟母 appears for the first time here, so please introduce her briefly, for example as 孟子的妈妈.
- (suggestion) 在那个城市 → 在他们住的城市: It would be clearer to say 他们住的城市 because no city has been introduced for 那个城市 to refer to.

**Coherence: connectors**
- (suggestion) 原来买不了房 → 原来是因为买不了房: It would be more natural to use 原来是因为 to clearly introduce the reason.

### Scene 2

> 这个城市老是很吵，不是人吵架，就是都叫，害得孟子一直不能睡觉。在那儿，孟母也找不到工作。孟子和妈妈要又一个次搬了家。在第三个城市，孟母找到工作，在商店做衣服。

**Grammar**
- 就是都叫 → 就是有人叫: 都 needs a clear plural referent. Use 有人 here to say that people are shouting.
- …要又一个次搬了家 → …要又一个次搬家: After 要, do not use completed-action 了. 要搬家 describes a planned action, not a completed one.

**Vocabulary**
- (suggestion) 孟母找到工作 → 孟母找到了工作: It would be more natural to say 找到了工作, because finding the job is a completed action.

**Coherence: connectors**
- 孟子和妈妈要又一个次搬了家 → 孟子和妈妈要再一次搬了家: use 再一次 here because it means “one more time.”

### Scene 3

> 孟子在那个商店也找了到工作，可是不是做衣服的工作，而是喜欢的工作。孟子学习馆学了十五年，他的学习和他的旅行经验很重要，对他很多好处。他是大人的时候，他成为很有名的哲人。

**Grammar**
- …做衣服的工作，而是喜欢的工作 → …做衣服的工作: The phrase 而是喜欢的工作 does not fit the meaning here, so delete it.
- 孟子学习馆学了十… → 孟子在学习馆学了十…: Use 在 before a place where an action happens: 在学习馆学了十五年.
- 对他很多好处 → 对他有很多好处: Use 有 in 对他有很多好处 to say something has many benefits for him.

**Vocabulary**
- …在那个商店也找了到工作 → …在那个商店也找到了到工作: The person successfully finds a job, so use 找到find, not 找look for.
- 他是大人的时候 → 他长大后: Use the established time expression 长大后, not the literal combination 是大人的时候.
- (suggestion) 他成为很有名的哲人 → 他成为了很有名的哲人: It would be more natural to add 了 after 成为 to show the completed change: 成为了很有名的哲人.

**Coherence: reference**
- 他成为很有名的… → 成为很有名的…: The subject is already clear from the previous clause, so delete 他. Chinese uses zero form here.

## mengmu_samples#10

### Scene 1

> 孟子小的时候，从早到晚都跟朋友玩。孟子和他的朋友喜欢玩在墓地里，装祭拜。孟子五岁的时候，跟妈妈搬家。他们搬家不是因为孟子玩得太多，而是因为妈妈认为他们的家离墓地太近。

**Grammar**
- …他的朋友喜欢玩在墓地里 → …他的朋友喜欢在墓地里玩: 墓地里 is the location, so use 在+Place before the action: 在墓地里玩.
- (suggestion) 而是因为妈妈认为他们… → 而是妈妈认为他们…: It would be more natural to say 而是妈妈认为…… because 而是 already introduces the contrasting reason, so 因为 is unnecessary.

**Vocabulary**
- 装祭拜 → 装作祭拜: Use 装作 before a verb phrase. Here, say 装作祭拜.

**Coherence: reference**
- ⟦孟子⟧小的时候: This character appears for the first time, so please introduce 孟子 briefly with an identifying noun phrase, not only his name.

**Other**
- (suggestion) 跟妈妈搬家 → 跟妈妈搬家了: It would be more natural to add 了 after 搬家 to show the move was completed.

### Scene 2

> 妈妈认为，住离墓地太近，害得孟子的心气。孟子和孟母搬到子思老师的家，跟子思老师住。孟母帮子思打扫房间和做饭。子思帮孟母教她的儿子。因为孟子现在没有朋友，他老是读书。

**Grammar**
- 住离墓地太近 → 住得离墓地太近: Use 得 after 住 to introduce the degree result: 住得离墓地太近.
- (suggestion) …子思老师的家，跟子思老师住 → …子思老师的家住: It would be more natural to delete 跟子思老师 because 搬到子思老师的家 already shows where they will live.

**Vocabulary**
- 害得孟子的心气 → 伤了孟子的心气: 害得 needs a harmful result after 孟子的心气. Here, 伤了孟子的心气 is the natural expression.

**Coherence: reference**
- 孟子和⟦孟母⟧搬到子思老师…: 孟母 appears for the first time, so please introduce her briefly, for example 孟子的妈妈孟母.

**Coherence: connectors**
- (suggestion) 他老是读书 → 所以他老是读书: It would be more natural to add 所以 to show that having no friends is the reason for reading books often.

### Scene 3

> 子思认为，对孩子来说，读书最重要，特别是学哲学。孟子不是练习写文章，就是看哲学书。孟子从五岁一直学哲学。他才五岁就学哲学，难怪他成为很有名的哲学家。

**Grammar**
- 孟子从五岁一直学哲学 → 孟子从五岁起一直学哲学: After 从五岁, add 起 to show the starting point: 从五岁起一直学哲学.
- 难怪他成为很有名的哲学… → 难怪他成为了很有名的哲学…: Becoming a famous philosopher is a completed event, so use 了 after 成为.

**Vocabulary**
- 就是看哲学书 → 就是看到哲学书: The person actually sees the philosophy books, so use 看到see, not 看look.

**Coherence: reference**
- 难怪他成为很有名的… → 难怪成为很有名的…: 孟子 is already clear from the previous sentence, so 他 is redundant. Chinese uses zero form here.

## mengmu_samples#12

### Scene 1

> 古代，孟子跟孟母住在墓地的旁边。可是孟母注意，住在墓地的旁边影响孟子。他常常跟朋友们祭拜玩，所以孟母决定他们会搬家。这次，他们住在城市里的商店的旁边，从早到晚很吵。

**Grammar**
- …常常跟朋友们祭拜玩 → …常常跟朋友们玩祭拜的游戏: Put 玩 before the activity being played. Say 玩祭拜的游戏.

**Vocabulary**
- (suggestion) …在墓地的旁边影响孟子 → …在墓地的旁边会影响孟子: It would be more natural to say 会影响孟子 to show that living beside a cemetery may have this result.
- 所以孟母决定他们会搬家 → 所以孟母决定搬家: After 决定, use the action directly: 决定搬家. Do not add 他们会 here.

**Coherence: reference**
- ⟦孟子⟧跟孟母住在墓…: This character appears for the first time, so please introduce 孟子 briefly with an identifying noun phrase, not only his name.
- 孟子跟⟦孟母⟧住在墓地的旁…: This character appears for the first time, so please introduce 孟母 briefly, for example as 孟子的妈妈.

**Coherence: connectors**
- 可是孟母注意 → 可是孟母注意到: Use 注意到 when you mean “notice” or “realize” a fact.

### Scene 2

> 城市也有点儿危险。害得孟母只好一直陪孟子。孟子也没有朋友，难怪他老是看起来不高兴。住在商店的旁边不是适合孟子，而是让他觉得很伤心。

**Grammar**
- (suggestion) …母只好一直陪孟子 → …母只好一直陪着孟子: It would be more natural to say 一直陪着孟子. 着 shows that 陪 is a continuing action.

**Vocabulary**
- …在商店的旁边不是适合孟子 → …在商店的旁边不但不适合孟子: this sentence needs the paired structure 不但……而且…… to add a second negative result.
- 而是让他觉得很伤… → 而且让他觉得很伤…: 不但 should pair with 而且, not 而是.

### Scene 3

> 所以，孟母和孟子搬到学校的旁边住。才五岁孟子开始学哲学。在学校，孟子不是看书，就是练习写字。将来，他成为中国的一个非常有名的哲学家。

**Vocabulary**
- (suggestion) 他成为中国的一… → 他会成为中国的一…: It would be more natural to add 会 to show that becoming a famous philosopher was his future result. 成为 is correctly followed by the profession noun 哲学家.

**Coherence: temporality (了/着/在)**
- 将来 → 后来: 将来 means “in the future,” but this is a later event in a past story. Use 后来 for the next story event.

**Coherence: connectors**
- 才五岁孟子开始学哲… → 才五岁时孟子开始学哲…: Use 时 after an age phrase to show the time when an action happened: 才五岁时。
- (suggestion) 才五岁孟子开始学哲学 → 才五岁孟子就开始学哲学: It would be more natural to use 才Num.就V. to emphasize that he started learning at the early age of five.

## mengmu_samples#18

### Scene 1

> 古代的时候，有一个男孩名字叫孟子。孟子和孟子的妈妈两个人住在很穷的农村。他们住的地方旁边是个墓地，墓地老是有很多人祭拜。因为人们在祭拜，他们一直在哭。孟子和孟子的妈妈住在这里才一个星期就觉得受不了了，而且害得孟子的学习。

**Grammar**
- 古代的时候 → 在古代: 古代 is the location/time setting, so use 在+Place: 在古代.

**Vocabulary**
- 而且害得孟子的学习 → 而且影响了孟子的学习: 害得 needs a harmful result after the person or noun. 影响了 fits here because 学习 is the noun affected.
- (suggestion) 而且害得孟子的学习 → 而且害得孟子学习: It would be more natural to say 孟子学习 without 的 here.

**Coherence: connectors**
- (suggestion) 他们一直在哭 → 所以他们一直在哭: It would be more natural to add 所以 to show that the people’s crying is the result of their worshipping.

### Scene 2

> 孟子的妈妈觉得孟子取得良好的教育是很重要的，所以孟子的妈妈认为这样的地方对儿子的教育不太好，就打算跟孟子搬家。孟子的妈妈带孟子不是搬到城市，而是搬到了孟子老师的家。

**Grammar**
- (suggestion) 孟子的妈妈带孟子不是搬… → 孟子的妈妈不是带孟子不是搬…: It would be more natural to use 不是……而是…… to contrast the two places.
- …的妈妈带孟子不是搬到城市 → …的妈妈带孟子没有搬到城市: For a completed action that did not happen, use 没有, not 不是.

**Vocabulary**
- …妈妈觉得孟子取得良好的教育是… → …妈妈觉得孟子接受良好的教育是…: 取得 does not normally collocate with 教育; use 接受 instead.
- (suggestion) 就打算跟孟子搬家 → 就打算让孟子搬家: It would be more natural to use 让 when the mother makes Mengzi move. 跟 means “with,” while 让 shows that she tells him to do the action.

**Coherence: connectors**
- (suggestion) 所以孟子的妈妈认为这样… → 所以孟子妈妈认为这样…: It would be more natural to omit 的 here and say 孟子妈妈.
- (suggestion) …的地方对儿子的教育不太好 → …的地方对儿子不太好: It would be more natural to say 这样的地方对儿子不太好; 的教育 is not needed here.

### Scene 3

> 孟子跟他的老师从早到晚学习，难怪他的成绩很快就进步了很多。孟子学习的时候，孟子的妈妈不是待在家里就是编织衣服赚钱。以后孟子成为了中国有名的哲学家。

**Grammar**
- …子的妈妈不是待在家里就是编织衣服赚钱 → …子的妈妈不是在家里就是待编织衣服赚钱: 家里 is the location, so use 在+Place before the action: 在家里待.

**Vocabulary**
- (suggestion) …待在家里就是编织衣服赚钱 → …待在家里就是织布赚钱: It would be more natural to say 织布 for the activity of making cloth to earn money.

- (suggestion) …地跟朋友们玩玩儿 → …地跟朋友们玩儿: It would be more natural to say 玩儿 here. Delete the extra 玩 to avoid repetition.

### Scene 2

> 他的妈妈觉得在墓地玩儿，害得，所以他们搬家。搬家对孟子有好的影响，他才五岁，可是每天不是写字就是帮妈妈的工作。

## mengmu_samples#32

### Scene 1

> 有一天孟子去了墓地玩儿，但是他妈妈觉得这是不合适的地方让孩子玩，所以她决定了他们会搬家找更好的地方。她恐怕儿子的童年不会幸福，而且住在这儿教育不太好。因为她望子成龙，所以她会一直搬家才能找到质量好的教育。然后他们搬到了离城市更近的地方。

**Grammar**
- …妈妈觉得这是不合适的地方让孩子玩 → …妈妈觉得这是不适合让孩子玩的地方: 不适合 must take the action phrase 让孩子玩 as its complement before 地方.
- 而且住在这儿教育不太好 → 而且这儿的教育不太好: use 这儿的 to modify 教育.

**Vocabulary**
- 所以她会一直搬家才能… → 所以她要一直搬家才能…: 会 does not naturally form the conditional pattern with 才能 here; use 要...才能 instead.

**Coherence: reference**
- 有一天⟦孟子⟧去了墓地玩儿: 孟子 appears for the first time, so please introduce him briefly, for example 孟子这个孩子.
- 所以她会一直搬家才… → 所以会一直搬家才…: 她 is already clear from the previous clause, so delete it; Chinese uses zero form here.

**Coherence: temporality (了/着/在)**
- 所以她决定了他们会搬家找… → 所以她决定他们会搬家找…: 决定 is a mental-state verb here, so use no 了.

**Coherence: connectors**
- (suggestion) 有一天孟子去了墓地玩儿 → 有一天孟子去墓地玩儿: It would be more natural to delete 了 and use a sequence phrase such as 后来 to show how this sentence connects to the narrative.

**Other**
- (suggestion) …搬家找更好的地方 → …搬家找更好的: It would be more natural to delete 地方 because 更好的 already expresses the thing she wants to find.

### Scene 2

> 他们住才一月就又搬家。古代的时候，一般人不喜欢卖东西的人。但是孟子老是跟这些卖东西的人常常玩儿，害得妈妈着急得很，因为她恐怕儿子会成为跟他们很像。她告诉了孟子：他们不是朋友，而是不好的人。

**Grammar**
- …一月就又搬家 → …一月就又搬家了: Add sentence-final 了 because the move was completed: 又搬家了.
- 古代的时候 → 在古代: 古代 is the time/location background, so use 在+Place before the action: 在古代.

**Vocabulary**
- 他们住才一月就又搬家 → 他们才住一月就又搬家: use 才住 because 才 goes before the verb to show the short duration “only lived for one month.”
- (suggestion) 因为她恐怕儿子会成为跟… → 因为她担心儿子会成为跟…: It would be more natural to say 担心 here, because it directly expresses that the mother worries about her son.
- …她恐怕儿子会成为跟他们很像 → …她恐怕儿子会变得跟他们很像: use 变得 before the adjective phrase 很像. 成为 is used for becoming a person, role, or thing.

**Coherence: temporality (了/着/在)**
- 她告诉了孟子：他们不… → 她告诉孟子：他们不…: 告诉 introduces quoted speech, so use no 了 for the speaking word: 她告诉孟子：……

**Other**
- 但是孟子老是跟这些卖东西… → 但是孟子跟这些卖东西…: 老是 is redundant because 常常 already expresses that Mengzi played with them often.

### Scene 3

> 你不是当数学家，而是当哲学家，不能当卖东西的人。所以他们又搬家。在他们第三个家，孟子学了怎么祭拜。妈妈感觉这个地方适合他们，告诉了孟子：我们找到了最后的家。在这儿妈妈让儿子从早到晚学习，他难怪成为有名的哲学家。

**Vocabulary**
- 而是当哲学家 → 而要当哲学家: Use the matching contrast 不要……而要…… here. It is more natural than pairing 不要 with 而是.
- (suggestion) 而是当哲学家 → 而是当哲学家的: It would be more natural to add 的 here to make the description sound more complete.
- (suggestion) …他们第三个家 → …他们第三个家里: A modified location with 家 normally uses 里. Say 在他们第三个家里.

- …是我觉得他们的吃的植物 → …是我觉得他们吃的植物: 他们 is the Subj. of 吃, so it does not need 的 here. Say 他们吃的植物.
- 让他们病人 → 让他们生病: 病人 is a noun for a sick person, but this sentence needs an action. Use 让他们生病.
- (suggestion) 对药 → 这个药药: After 吃, name the object being eaten: 吃这个药. 对药 is not an object here.

**Vocabulary**
- …植物可能特别是毒 → …植物可能特别有毒: Here the plant needs an Adj. to describe it. 有毒 means “poisonous”; 是毒 does not fit after 特别.

**Coherence: reference**
- ⟦神农⟧先看到很多病…: 神农 appears for the first time here, so please introduce him briefly with an identifying noun phrase, not only his name.
- 他想把花放在茶… → 想把花放在茶…: 他 is already clear from the previous clause, so delete it. Chinese uses zero form here.

**Coherence: connectors**
- …觉得这个植物可能特别是毒 → …觉得这个植物因此特别是毒: Use 因此 to show how this thought follows the previous sentence. It makes the connection between the clauses clear.

**Content**
- (suggestion) 所以他想找一个植物对药 → 所以他想找一种植物对药: It would be more natural to say 一种植物 when you mean one kind of plant.
- …想找一个植物对药 → …想找一个植物当药: Use 当药 after 植物 to say that the plant is used as medicine. 这个药 cannot follow 找一种植物 directly here.

### Scene 2

> 他不知道如果这把花对你的身体好，这就要看如果这把花毒不毒了。神农想找别的植物，但是这很麻烦。正好，他找到了别的花。他一吃花，很快就生病了。他的肚子疼死了。神农不知道他吃不吃灵芝或者夹竹桃。

**Grammar**
- …这把花毒不毒了 → …这把花毒不毒: No sentence-final 了 is needed here because this is not a completed action or a change of state.
- 神农不知道他吃不吃灵芝或者夹竹… → 神农不知道他吃的是灵芝或者夹竹…: To identify which plant he ate, use 是: 吃的是灵芝还是夹竹桃.

**Vocabulary**
- 这就要看如果这把花毒… → 这就要看到如果这把花毒…: Use 看到see when the narrative means actually seeing or finding out something, rather than 看look.
- (suggestion) …要看如果这把花毒不毒了 → …要看如果这把烟毒不毒了: It would be more natural to say 烟 here, because it collocates better with the intended situation.
- 别的人给了神农一个… → 给了神农一个…: 别的人 is redundant here, so delete it and begin with 给了神农一个灵芝.

**Coherence: reference**
- …如果这把花对你的身体好 → …如果这把花对他的身体好: This refers to Shennong’s body, so use 他的, not 你的.

**Coherence: connectors**
- 他不知道如果这把花对你的… → 他不知道这把花对你的…: After 不知道, use the question directly; do not add 如果 before an indirect question.
- …花对你的身体好 → …花对你的身体好不好: After 不知道, a yes/no indirect question needs an alternative form: 好不好.
- 这就要看如果这把花毒不毒… → 这就要看这把花毒不毒…: After 看, use the question directly: 看这把花毒不毒. Do not use 如果 here.
- …他吃不吃灵芝或者夹竹桃 → …他吃不吃灵芝还是夹竹桃: Use 还是, not 或者, for alternatives in an embedded question after 不知道.

### Scene 3

> 别的人给了神农一个灵芝。这个植物可以让神农更好。比方说，他会觉得更健康。吃灵芝以后，他可以再走。现在他觉得更好。最后，神农找到了很多植物，他可以用对药。这些植物让神农很高兴。神农想跟很多人分享他的新药。

**Vocabulary**
- …人给了神农一个灵芝 → …人给了神农一朵灵芝: 灵芝 normally uses the measure word 朵, not 个.
- (suggestion) …物可以让神农更好 → …物可以让神农变得更好: It would be more natural to say 让神农变得更好 when describing a change for the better.
- 他可以用对药 → 他可以用这些植物来做药: 用对药 does not mean “use plants to make medicine.” Use 用这些植物来做药 here.

**Coherence: temporality (了/着/在)**
- 吃灵芝以后 → 吃了灵芝以后: The eating is completed before the later action, so use 了completed: 吃了灵芝以后.
- (suggestion) …在他觉得更好 → …在他觉得更好了: It would be more natural to add 了completed/change because he has now become better: 觉得更好了.

- 古代的时候有一个人叫神… → 在古代有一个人叫神…: 古代 is the location/time setting, so use 在+Place before the action: 在古代有一个人叫神农。
- (suggestion) 神农听说一个远远的地… → 神农听说在一个远远的地…: It would be more natural to say 在一个很远的地方有一种植物, using 在+Place for the location.

- (suggestion) 神农听说一个远远的地方有一种… → 神农听说一个很远的地方有一种…: It would be more natural to say 很远的地方. 很远 is the standard expression here.

**Coherence: reference**
- 他不知道什么东… → 不知道什么东…: 他 is already clear from the close continuation, so delete it; Chinese uses zero form here.
