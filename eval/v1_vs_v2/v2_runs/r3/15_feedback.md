## mengmu_samples#10

### Scene 1

> 孟子小的时候，从早到晚都跟朋友玩。孟子和他的朋友喜欢玩在墓地里，装祭拜。孟子五岁的时候，跟妈妈搬家。他们搬家不是因为孟子玩得太多，而是因为妈妈认为他们的家离墓地太近。

**Grammar**
- …他的朋友喜欢玩在墓地里 → …他的朋友喜欢在墓地里玩: 墓地里 is the location, so use 在+Place before the action: 在墓地里玩.
- 跟妈妈搬家 → 跟妈妈搬了家: This move was completed in the past, so add 了 after 搬: 搬了家.

**Vocabulary**
- 装祭拜 → 装作祭拜: 装 needs 作 to mean “pretend to.” Use 装作+V., as in 装作祭拜.

**Coherence: reference**
- ⟦孟子⟧小的时候: This character appears for the first time, so please introduce 孟子 briefly with an identifying noun phrase, not only his name.

**Coherence: connectors**
- (suggestion) 而是因为妈妈认为他们… → 而是妈妈认为他们…: It would be more natural to delete 因为, because 而是 already introduces the real reason.

### Scene 2

> 妈妈认为，住离墓地太近，害得孟子的心气。孟子和孟母搬到子思老师的家，跟子思老师住。孟母帮子思打扫房间和做饭。子思帮孟母教她的儿子。因为孟子现在没有朋友，他老是读书。

**Grammar**
- 住离墓地太近 → 住得离墓地太近: Use 得 after 住 to introduce the degree complement: 住得离墓地太近.
- (suggestion) …子思老师的家，跟子思老师住 → …子思老师的家住: It would be more natural to delete 跟子思老师 because 子思老师的家 already shows where they live.

**Vocabulary**
- 害得孟子的心气 → 害得孟子心情不好: After 害得 + N/sb., use a harmful result. 心情不好 gives the result for 孟子.

**Coherence: reference**
- 孟子和⟦孟母⟧搬到子思老师…: 孟母 appears for the first time here, so please introduce her briefly, for example as 孟子的妈妈.

**Coherence: connectors**
- (suggestion) 他老是读书 → 所以他老是读书: It would be more natural to use 所以 to show the result: because he has no friends, he reads books often.

### Scene 3

> 子思认为，对孩子来说，读书最重要，特别是学哲学。孟子不是练习写文章，就是看哲学书。孟子从五岁一直学哲学。他才五岁就学哲学，难怪他成为很有名的哲学家。

**Grammar**
- 孟子从五岁一直学哲学 → 孟子从五岁起一直学哲学: Use 从五岁起一直学哲学 to show that the action started at age five and continued.

**Vocabulary**
- 就是看哲学书 → 就是看到哲学书: 孟子 actually sees the philosophy books, so use 看到see, not 看look.

**Coherence: reference**
- 难怪他成为很有名的… → 难怪成为很有名的…: 孟子 is already clear from the previous clause, so delete the redundant 他; Chinese uses zero form here.

## mengmu_samples#32

### Scene 1

> 有一天孟子去了墓地玩儿，但是他妈妈觉得这是不合适的地方让孩子玩，所以她决定了他们会搬家找更好的地方。她恐怕儿子的童年不会幸福，而且住在这儿教育不太好。因为她望子成龙，所以她会一直搬家才能找到质量好的教育。然后他们搬到了离城市更近的地方。

**Grammar**
- …妈妈觉得这是不合适的地方让孩子玩 → …妈妈觉得这是不适合让孩子玩的地方: the whole action 让孩子玩 needs to modify 地方, so use the 的 structure.

**Vocabulary**
- 所以她会一直搬家才能… → 所以她要一直搬家才能…: 会 does not normally collocate with 一直搬家才能 in this necessary-condition meaning; use 要…才能 instead.

**Coherence: reference**
- 有一天⟦孟子⟧去了墓地玩儿: This character appears for the first time, so please introduce 孟子 briefly, for example 孟子小时候.
- 而且住在这儿教育不太好 → 而且这儿的教育不太好: use 的 to show that 这儿 modifies 教育.
- 所以她会一直搬家才… → 所以会一直搬家才…: 她 is redundant because the subject is already clear from the previous clause; Chinese uses zero form here.

**Coherence: temporality (了/着/在)**
- 所以她决定了他们会搬家找… → 所以她决定他们会搬家找…: 决定 is a mental state verb here, so use no 了.

**Coherence: connectors**
- (suggestion) 有一天孟子去了墓地玩儿 → 有一天孟子去墓地玩儿: It would be more natural to say 去墓地玩儿 without 了 here; this opening sentence does not need 了 to connect to a previous event.

**Other**
- (suggestion) …搬家找更好的地方 → …搬家找更好的: It would be more natural to delete 地方 because 更好的 already expresses the intended meaning here.

### Scene 2

> 他们住才一月就又搬家。古代的时候，一般人不喜欢卖东西的人。但是孟子老是跟这些卖东西的人常常玩儿，害得妈妈着急得很，因为她恐怕儿子会成为跟他们很像。她告诉了孟子：他们不是朋友，而是不好的人。

**Grammar**
- 他们住才一月就又搬… → 他们住了才一月就又搬…: Use 了 after 住 to show that this period of living was completed before they moved again.
- 古代的时候 → 在古代: 古代 is the location/time setting, so use 在+Place before the action: 在古代。

**Vocabulary**
- 他们住才一月就又搬家 → 他们住才一个月就又搬家: Use 一个月 for a duration of one month; 一月 is usually the name of the month January.
- (suggestion) …一月就又搬家 → …一月就又搬家了: It would be more natural to add 了 after 搬家 to show the move was completed.
- …她恐怕儿子会成为跟他们很像 → …她恐怕儿子会变得跟他们很像: Use 变得 before the adjective phrase 很像. 成为 is used before a noun or role.

**Coherence: reference**
- (suggestion) …子：他们不是朋友 → …子：他们不是你的朋友: It would be clearer to add 你的 to show that these people are not Mencius's friends.

**Coherence: temporality (了/着/在)**
- 她告诉了孟子：他们不… → 她告诉孟子：他们不…: 告诉 introduces quoted speech, so use no 了 for the speaking word.

**Coherence: connectors**
- …些卖东西的人常常玩儿 → …些卖东西的人玩儿: 老是 already means “often/always,” so 常常 is redundant here.

**Other**
- (suggestion) 因为她恐怕儿子会成为跟… → 因为她担心儿子会成为跟…: It would be more natural to say 担心 because it directly expresses that the mother worries about her son.

### Scene 3

> 你不是当数学家，而是当哲学家，不能当卖东西的人。所以他们又搬家。在他们第三个家，孟子学了怎么祭拜。妈妈感觉这个地方适合他们，告诉了孟子：我们找到了最后的家。在这儿妈妈让儿子从早到晚学习，他难怪成为有名的哲学家。

**Vocabulary**
- (suggestion) 而是当哲学家 → 而是当哲学家的: It would be more natural to say 而是当哲学家的. The particle 的 links the contrastive description to the following person.
- …他们第三个家 → …他们第三个家里: 在他们第三个家 does not normally collocate as a place expression; use 在他们第三个家里 instead.
- 他难怪成为有名的哲… → 难怪他成为有名的哲…: 难怪 normally comes before the subject. Use 难怪他成为有名的哲学家.

**Coherence: temporality (了/着/在)**
- (suggestion) 孟子学了怎么祭拜 → 孟子学会了怎么祭拜: It would be more natural to say 孟子学会了怎么祭拜. 学会 means “learn to be able to do,” while 学 alone does not clearly show this result.
- 告诉了孟子：我们找… → 告诉孟子：我们找…: 告诉 introduces quoted speech, so use no 了 for the speaking word.

**Coherence: connectors**
- (suggestion) …以他们又搬家 → …以他们又搬家了: It would be more natural to say 又搬家了. 又 shows that moving happened again, and 了 marks the completed move.

## mengmu_samples#45

### Scene 1

> 古代的时候，一个男孩子跟他的妈妈住在中国。他叫孟子。他们住在墓地的旁边，所以孟子老是祭拜。孟子不是祭拜，就是跟朋友聊天。他很喜欢他的城市，但是城市有才两个学校，都很小。

**Grammar**
- 古代的时候 → 在古代: 古代 is the location/time setting, so use 在+Place before the action: 在古代。
- 但是城市有才两个学校 → 但是城市才有两个学校: Put 才 before 有 here: 才有两个学校 means “there are only two schools.”

**Vocabulary**
- …是城市有才两个学校 → …是城市有才两所学校: Use 所 for schools: 一所学校. 个 is a general measure word, but 所 is the usual measure word for a school.

**Coherence: reference**
- 一个男孩子跟⟦他⟧的妈妈住在中…: This character appears for the first time, so please introduce his mother briefly with a noun phrase, such as 孟子的妈妈, instead of only using 他。
- (suggestion) …孟子老是祭拜 → …孟子老是祭拜他们: It would be clearer to add 他们, because both Mengzi and his mother live next to the cemetery and may worship there.

### Scene 2

> 他的妈妈不是不喜欢他们的城市，而是想孟子有很好的教育。他们搬家到有很多学校的城市。他们从早到晚走路，孟子一直抱怨。

**Vocabulary**
- 而是想孟子有很好的… → 而是想让孟子有很好的…: 想 cannot be followed directly by a person and a noun here. Use 想让 + person + verb: 想让孟子接受很好的教育.
- 而是想孟子有很好的教育 → 而是想孟子接受很好的教育: We normally say 接受很好的教育, not 有很好的教育. Use 接受 for receiving an education.
- (suggestion) 他难怪抱怨 → 难怪他抱怨: It would be more natural to put 难怪 before the subject: 难怪他抱怨. 难怪 introduces the reason that explains the subject's action.

**Coherence: temporality (了/着/在)**
- (suggestion) 他们搬家到有很多学校… → 他们搬到有很多学校…: It would be more natural to say 搬到有很多学校的城市. Here 搬到 already expresses moving to the city.
- (suggestion) 他们搬家到有很多学校的… → 他们搬家到了有很多学校的…: It would be more natural to add 了 because the move is completed in the story: 搬到了. This is 了completed.

### Scene 3

> 他难怪抱怨，他想他的朋友，因为他不要离开他的城市。他的妈妈找到孟子一个老师。跟老师孟子学最重要的文学，所以他成为哲学家。

**Grammar**
- (suggestion) …妈妈找到孟子一个老师 → …妈妈找到孟子的老师: It would be more natural to say 孟子的老师. 孟子 describes 老师, so use 的.
- 跟老师孟子学最重要的文… → 孟子跟老师学最重要的文…: 孟子 is the subject, so put it before 跟老师: 孟子跟老师学最重要的文学.

**Vocabulary**
- (suggestion) 因为他不要离开他的城市 → 因为他不想离开他的城市: It would be more natural to say 想 here: 因为他不想离开他的城市 means he does not want to leave his city.

**Coherence: reference**
- 他想他的朋友 → 想他的朋友: 他 is already clear from the previous clause, so it is redundant. Delete it; Chinese uses zero form here.
- 因为他不要离开他的… → 因为不要离开他的…: 他 is already clear in the close continuation, so it is redundant. Delete it; Chinese uses zero form here.

**Coherence: temporality (了/着/在)**
- (suggestion) 所以他成为哲学家 → 所以他成为了哲学家: It would be more natural to use 了completed because becoming a philosopher is a completed change in the story.

**Other**
- 他的妈妈找到孟子一个老师 → 他的妈妈给孟子找到一个老师: Use 给孟子 to show that his mother found a teacher for Mencius. The person receiving the help comes after 给.

## shennong_samples#8

### Scene 1

> 古代的时候，有一个人叫神农。一天，神农正在路上走，一看很多人正在吃一些植物。一些人一吃植物就生病了，神农想帮别人。所以想知道哪些植物能吃，哪些植物不能吃。

**Grammar**
- 古代的时候 → 在古代: 古代 is the story’s time/place setting, so use 在+Place before the action: 在古代。
- (suggestion) 哪些植物不能吃 → 哪些不能吃: It would be more natural not to repeat 植物. After 哪些植物能吃, you can say 哪些不能吃.

**Vocabulary**
- 一看很多人正在吃… → 看到很多人正在吃…: Shennong actually sees this situation, so use 看到see, not 看look.

**Coherence: temporality (了/着/在)**
- (suggestion) 神农想帮别人 → 神农想帮了别人: It would be more natural to say 帮了别人 if this helping is completed in the story; use 了completed for a completed action.

### Scene 2

> 然后，神农开始尝很多植物，比方说他吃过生姜、芥兰和菠菜。一些植物吃真好，特别是黄瓜。但是，一些植物毒得很，特别是夹竹桃。

**Grammar**
- 一些植物吃真好 → 一些植物很好吃: 很好吃 is the usual adjective phrase for “tastes good.” Say 植物很好吃, not 吃真好.

**Vocabulary**
- (suggestion) 一些植物毒得很 → 一些植物有毒得很: It would be more natural to use the Adj. 有毒 here: 有毒 means “poisonous.”
- (suggestion) 一些植物毒得很 → 一些植物毒: It would be more natural to say 有毒, without 得很. 有毒 is already an Adj. phrase describing the plants.

### Scene 3

> 一个人对神农说，麻烦我们可以吃什么植物？神农说，这就要看你想不想生病了。以后，神农告诉别人一些植物能吃，一些植物不能吃。

**Grammar**
- (suggestion) 一些植物不能吃 → 一些不能吃: It would be more natural to omit 植物 here because it is repeated from the earlier phrase 一些植物能吃.

**Vocabulary**
- 麻烦我们可以吃什… → 请问我们可以吃什…: 麻烦 means “trouble,” not a polite question opener. Use 请问 to begin a polite question.
- 这就要看你想不想生病… → 这就要看你想不想生病…: Here 看 means “depend on” in 要看……, so it is already correct. Do not change it to 看到, which means actually “see.”

## shennong_samples#19

### Scene 1

> 古代的时候，一个男人觉得植物很有意思。他叫神农。有的植物吃了以后他的肚子疼死了，可是有的吃了以后很舒服。他找很多植物。

**Grammar**
- 古代的时候 → 在古代: 古代 is the location/time setting for the action, so use 在+Place before the action: 在古代。
- 他找很多植物 → 他找了很多植物: 找 is a completed action in the story, so add 了: 找了。

**Vocabulary**
- 可是有的吃了以后很舒… → 可是有的他吃了以后很舒…: The plants are not doing the eating. Add 他 to show that he eats them.
- (suggestion) 可是有的吃了以后很舒服 → 可是有的吃了之后很舒服: It would be more natural to say 吃了之后 here. 之后 means “after” in this completed action sequence.

**Coherence: reference**
- ⟦他⟧叫神农: This character appears for the first time, so please introduce him briefly with an identifying noun phrase, not only 他.
- 有的植物吃了以后他的… → 有的植物他吃了以后他的…: The plants are not doing the eating. Add 他 to show that he eats the plants.

**Coherence: temporality (了/着/在)**
- 凉山很大的山 → 上了很大的山: This is a completed action in the story, so use 上了 with 了completed.

### Scene 2

> 凉山很大的山，这也找植物。一天，他找到黄色的花。他听说你跟黄色的花做茶很有用。比方说，你的头发疼死，这冰茶是药。他一喝茶就很不舒服。

**Grammar**
- 他找到黄色的花 → 他找了到黄色的花: The discovery is completed in the story, so add 了: 找到了.
- 你的头发疼死 → 你的头发疼得要死: Use 得 before the degree complement: 疼得要死.

**Vocabulary**
- 他听说你跟黄色的花做茶… → 他听说你用黄色的花做茶…: Use 用 to say that the tea is made with yellow flowers.
- 你的头发疼死 → 你的头疼死: Use 头疼 for “have a headache.” 发 means “hair,” so delete it here.
- (suggestion) 他一喝茶就很不舒服 → 他一喝茶就觉得很不舒服: It would be more natural to say 觉得很不舒服 to show that he feels uncomfortable.

**Coherence: reference**
- 这也找植物 → 他也找植物: Use 他 because this refers to Shennong, not to “this.”
- 你的头发疼死 → 的头发疼死: No second-person subject is intended here, so delete 你.
- 这冰茶是药 → 这种茶是药: Use 这种茶 to refer to this kind of tea from the previous context.

### Scene 3

> 糟糕，这黄色的花是夹竹桃，特别是毒。正好在这儿，灵芝药的夹竹桃他吃完了，也写一个课文的植物。谢谢神农。

**Grammar**
- 灵芝药的夹竹桃他… → 灵芝是药的夹竹桃他…: Use 是 to link 灵芝药 with its description: 灵芝药是……。
- 也写一个课文的植物 → 也写一个关于这种植物的课文: 课文的植物 means “a plant of the text.” Use 关于这种植物的课文 to show that the text is about this plant.

**Vocabulary**
- 特别是毒 → 特别有毒: The structure needs an Adj. to describe 夹竹桃, but 毒 is a noun. Use 有毒.
- 也写一个课文的植… → 也写了一个课文的植…: The writing action is completed, so add 了 after 写.
- 也写一个课文的植物 → 也写一篇课文的植物: 篇 is the normal measure word for 课文, not 个.

**Coherence: connectors**
- 灵芝药的夹竹… → 有灵芝药的夹竹…: Use 有 before 灵芝 to show that the medicine exists: 有灵芝药。

## shennong_samples#33

### Scene 1

> 古代时候，人不知道他们能吃什么植物，常常一吃就死。但是不知道为什么，没有办法。所以有一天，神农出去试一试很多种植物，告诉人什么植物是安全什么是危险。

**Grammar**
- 告诉人什么植物是安… → 告诉人们什么植物是安…: Use 人们 when you mean people in general.
- …么植物是安全什么是危险 → …么植物是安全的什么是危险: 安全 describes the omitted noun 植物, so use 的: 是安全的.
- …全什么是危险 → …全什么是危险的: 危险 describes the omitted noun 植物, so use 的: 是危险的.

**Vocabulary**
- 神农出去试一试很多种植物 → 神农出去尝了很多种植物: 试一试 does not normally collocate with plants in this situation; use 尝了 instead.

**Coherence: reference**
- (suggestion) 人不知道他们能吃什么植物 → 人不知道自己能吃什么植物: It would be more natural to use 自己 to refer back to generic 人.
- ⟦神农⟧出去试一试很…: 神农 appears for the first time, so please introduce him briefly with an identifying noun phrase.

**Other**
- 古代时候 → 古代: 时候 is redundant because 古代 already expresses the time.

### Scene 2

> 发现有的植物对身体非常好，特别是茶，让肚子感觉又暖和又清楚。他告诉朋友：“你吃哪种植物，这就要看你的口味。比方说，你爱吃甜的，可能喜欢糖。”他最喜欢吃花，除了夹竹桃以外，什么都花想吃。

**Grammar**
- 什么都花想吃 → 什么花都想吃: Put 花 after 什么 and before 都: 什么花都想吃. This word order means “want to eat every kind of flower.”

**Vocabulary**
- …感觉又暖和又清楚 → …感觉又暖和又舒服: 清楚 cannot describe how your stomach feels. Use 舒服 for a warm, comfortable stomach feeling.
- 这就要看你的口味 → 这就要看你的口味: It would be more natural to say 看 here: 口味 is something you consider or judge, not something you literally 看到see.

**Coherence: connectors**
- 可能喜欢糖 → ，这样可以吃糖喜欢糖: Use ，这样可以吃糖 to show the connection: if you like sweet food, then you can eat candy.

### Scene 3

> 他发现这个口味，一百岁时候，不小心吃了毒的花。一吃就开始死。但是生病时候告诉人什么植物是药，什么植物是毒。

**Grammar**
- 但是生病时候告诉人什… → 但是生病的时候告诉人什…: Use 的 before 时候 in this time phrase: 生病的时候.

**Vocabulary**
- 一百岁时候 → 一百岁的时候: 一百岁的时候 is the established time expression. Use 的 before 时候.
- 不小心吃了毒的花 → 不小心吃了有毒的花: Here the structure needs an adjective before 花, but 毒 is a noun. Use 有毒的花.
- (suggestion) 什么植物是毒 → 什么是毒: It would be more natural to avoid repeating 植物. After 什么植物是药, you can say 什么是毒.
- 什么植物是毒 → 什么植物有毒: Here the structure needs an adjective, but 毒 is a noun. Use 有毒: 什么植物有毒.

**Coherence: reference**
- (suggestion) 一吃就开始死 → 一吃就会死: It would be more natural to say 一吃就会死. 会 shows the result that will happen after eating it.

**Content**
- (suggestion) 一吃就开始死 → 一吃就开始死亡: It would be more natural to use 开始死亡 here; 死 is not normally used after 开始 for one person.
