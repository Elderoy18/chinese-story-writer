## mengmu_samples#10

### Scene 1

> 孟子小的时候，从早到晚都跟朋友玩。孟子和他的朋友喜欢玩在墓地里，装祭拜。孟子五岁的时候，跟妈妈搬家。他们搬家不是因为孟子玩得太多，而是因为妈妈认为他们的家离墓地太近。

**Grammar**
- …他的朋友喜欢玩在墓地里 → …他的朋友喜欢在墓地里玩: 墓地里 is the location, so use 在+Place before the action: 在墓地里玩.
- 装祭拜 → 装作祭拜: Use 装作 before a verb phrase. Say 装作祭拜.
- 跟妈妈搬家 → 跟妈妈搬家了: This move was completed in the past, so add 了 after 搬: 搬家了.
- (suggestion) 而是因为妈妈认为他们… → 而是妈妈认为他们…: It would be more natural to say 而是妈妈认为他们的家离墓地太近. 而是 already introduces the contrasting reason.

**Coherence: reference**
- ⟦孟子⟧小的时候: 孟子 appears for the first time here, so please briefly introduce him with an identifying noun phrase, not only his name.

### Scene 2

> 妈妈认为，住离墓地太近，害得孟子的心气。孟子和孟母搬到子思老师的家，跟子思老师住。孟母帮子思打扫房间和做饭。子思帮孟母教她的儿子。因为孟子现在没有朋友，他老是读书。

**Grammar**
- 住离墓地太近 → 住得离墓地太近: Use 得 after 住 before a distance complement: 住得离墓地太近.
- (suggestion) …子思老师的家，跟子思老师住 → …子思老师的家住: It would be more natural to delete 跟子思老师, because 搬到子思老师的家 already makes the location and living arrangement clear.

**Vocabulary**
- 害得孟子的心气 → 影响孟子的心气: 害得 needs a harmful result after the person or noun. 影响 can directly take an object here.
- (suggestion) 害得孟子的心气 → 害得孟子的心情: It would be more natural to say 心情 for a person's emotional state here.

**Coherence: reference**
- 孟子和⟦孟母⟧搬到子思老师…: 孟母 appears for the first time here, so please briefly introduce her, for example as 孟子的妈妈.

**Coherence: connectors**
- (suggestion) 他老是读书 → 所以他老是读书: It would be more natural to add 所以 to show that having no friends is the reason he reads often.

### Scene 3

> 子思认为，对孩子来说，读书最重要，特别是学哲学。孟子不是练习写文章，就是看哲学书。孟子从五岁一直学哲学。他才五岁就学哲学，难怪他成为很有名的哲学家。

**Vocabulary**
- 就是看哲学书 → 就是看到哲学书: 孟子 actually sees the philosophy books, so use 看到see, not 看look.
- 孟子从五岁一直学哲学 → 孟子从五岁起一直学哲学: After 从五岁, add 起 to mark the starting age: 从五岁起一直学哲学.

**Coherence: reference**
- 难怪他成为很有名的… → 难怪成为很有名的…: 孟子 is already clear from the previous clause, so delete the redundant 他. Chinese uses zero form here.

## mengmu_samples#32

### Scene 1

> 有一天孟子去了墓地玩儿，但是他妈妈觉得这是不合适的地方让孩子玩，所以她决定了他们会搬家找更好的地方。她恐怕儿子的童年不会幸福，而且住在这儿教育不太好。因为她望子成龙，所以她会一直搬家才能找到质量好的教育。然后他们搬到了离城市更近的地方。

**Grammar**
- …妈妈觉得这是不合适的地方让孩子玩 → …妈妈觉得这是不适合孩子玩的地方: use 不适合孩子玩的地方 to make 孩子玩 modify 地方 clearly.
- 而且住在这儿教育不太好 → 而且这儿的教育不太好: use 这儿的教育 to show that the education belongs to this place.

**Vocabulary**
- (suggestion) 所以她会一直搬家才能… → 所以她要一直搬家才能…: It would be more natural to use 要 instead of 会 here, because 要 naturally expresses her intention to keep moving.

**Coherence: reference**
- 有一天⟦孟子⟧去了墓地玩儿: 孟子 appears for the first time, so please introduce him briefly, for example 孟子小时候.
- 所以她会一直搬家才… → 所以会一直搬家才…: 她 is already clear from the previous clause, so delete it; Chinese uses zero form here.

**Coherence: temporality (了/着/在)**
- 所以她决定了他们会搬家找… → 所以她决定他们会搬家找…: 决定 is a mental state verb here, so use no 了.

**Coherence: connectors**
- (suggestion) 有一天孟子去了墓地玩儿 → 有一天孟子去墓地玩儿: It would be more natural to delete 了 here, so the sentence connects more smoothly to the following action.

**Other**
- (suggestion) …搬家找更好的地方 → …搬家找更好的: It would be more natural to delete 地方 because 更好的 already expresses the idea, and 地方 is redundant here.

### Scene 2

> 他们住才一月就又搬家。古代的时候，一般人不喜欢卖东西的人。但是孟子老是跟这些卖东西的人常常玩儿，害得妈妈着急得很，因为她恐怕儿子会成为跟他们很像。她告诉了孟子：他们不是朋友，而是不好的人。

**Grammar**
- 他们住才一月就又搬… → 他们住了才一月就又搬…: Use 了 after 住 to show the one-month stay is completed.
- 古代的时候 → 在古代: 古代 is the location/time setting, so use 在+Place before the action: 在古代。

**Vocabulary**
- 他们住才一月就又搬家 → 他们住才一个月就又搬家: Use 一个月 for a duration. 一月 usually means the month of January, while 一个月 means “one month.”
- …一月就又搬家 → …一月就又搬家了: Use 了 after 搬家 to show the moving action is completed.
- …她恐怕儿子会成为跟他们很像 → …她恐怕儿子会变得跟他们很像: Use 变得 because becoming similar is a change of state. 成为 is used for becoming an identity or role.

**Coherence: reference**
- …子：他们不是朋友 → …子：他们不是你的朋友: Add 你的 to make clear that these people are not Mencius's friends.

**Coherence: temporality (了/着/在)**
- 她告诉了孟子：他们不… → 她告诉孟子：他们不…: 告诉 introduces quoted speech, so use no 了 for the speaking word.

**Coherence: connectors**
- …些卖东西的人常常玩儿 → …些卖东西的人玩儿: 老是 and 常常 both express repeated actions, so 常常 is redundant here.

**Other**
- (suggestion) 因为她恐怕儿子会成为跟… → 因为她担心儿子会成为跟…: It would be more natural to say 担心 here because it directly expresses that the mother worries about her son.

### Scene 3

> 你不是当数学家，而是当哲学家，不能当卖东西的人。所以他们又搬家。在他们第三个家，孟子学了怎么祭拜。妈妈感觉这个地方适合他们，告诉了孟子：我们找到了最后的家。在这儿妈妈让儿子从早到晚学习，他难怪成为有名的哲学家。

**Vocabulary**
- (suggestion) 而是当哲学家 → 而是当哲学家的: It would be more natural to say 哲学家的 fixed expression for “philosopher,” rather than adding 的 after 当哲学家.
- 在他们第三个家 → 在他们的第三个家: 他们 needs 的 before 第三个家 to show possession: 他们的第三个家.
- …他们第三个家 → …他们第三个家里: Use 里 after 家 for this location: 在他们的第三个家里.
- (suggestion) 孟子学了怎么祭拜 → 孟子学会了怎么祭拜: It would be more natural to say 学会了怎么祭拜. 学会 means “learn to be able to do,” while 学 alone does not show that he mastered it.

**Coherence: temporality (了/着/在)**
- 告诉了孟子：我们找… → 告诉孟子：我们找…: 告诉 introduces quoted speech, so use no 了 after this speaking word.

**Coherence: connectors**
- (suggestion) …以他们又搬家 → …以他们又搬家了: It would be more natural to add 了: 又 shows that moving happened again, and 了 marks this move as completed.

## mengmu_samples#45

### Scene 1

> 古代的时候，一个男孩子跟他的妈妈住在中国。他叫孟子。他们住在墓地的旁边，所以孟子老是祭拜。孟子不是祭拜，就是跟朋友聊天。他很喜欢他的城市，但是城市有才两个学校，都很小。

**Grammar**
- 古代的时候 → 在古代: 古代 is the setting, so use 在古代 before the action.
- 但是城市有才两个学校 → 但是城市才有两个学校: Put 才 before 有: 才有 means “there are only.”

**Vocabulary**
- …是城市有才两个学校 → …是城市有才两所学校: Use 所 for schools: 一所学校. 个 is not the usual measure word for 学校.

**Coherence: reference**
- 一个男孩子跟⟦他⟧的妈妈住在中…: His mother appears for the first time here, so introduce her with a noun phrase, such as 妈妈, rather than only using 他.
- (suggestion) …孟子老是祭拜 → …孟子老是祭拜他们: It would be more natural to say 他们 to include both 孟子 and his mother.

### Scene 2

> 他的妈妈不是不喜欢他们的城市，而是想孟子有很好的教育。他们搬家到有很多学校的城市。他们从早到晚走路，孟子一直抱怨。

**Vocabulary**
- 而是想孟子有很好的教育 → 而是想让孟子受到很好的教育: After 想, use 让 before the person who will receive the action. Education is something 孟子 receives, so say 想让孟子受到很好的教育.
- 他难怪抱怨 → 难怪他抱怨: 难怪 normally comes before the subject. Say 难怪他抱怨.

**Coherence: temporality (了/着/在)**
- 他们搬家到有很多学校的… → 他们搬家到了有很多学校的…: The moving is completed in the story, so it takes 了completed: 搬家到了有很多学校的城市.

### Scene 3

> 他难怪抱怨，他想他的朋友，因为他不要离开他的城市。他的妈妈找到孟子一个老师。跟老师孟子学最重要的文学，所以他成为哲学家。

**Grammar**
- 他的妈妈找到孟子一个老师 → 他的妈妈给孟子找到一个老师: Use 给孟子 to show that his mother found a teacher for Mencius.
- 跟老师孟子学最重要的文学 → 孟子跟老师学最重要的文学: 孟子 should be the subject before 跟老师. Say 孟子跟老师学.

**Vocabulary**
- 他想他的朋友 → 他想念他的朋友: 想念 means “to miss” someone. Use 想念 for missing his friends.
- 因为他不要离开他的城市 → 因为他不想离开他的城市: 不想离开 means “does not want to leave.” 不要 is usually used for a command or refusal.

**Coherence: reference**
- 他想他的朋友 → 想他的朋友: 他 is already clear from the previous clause, so delete it; Chinese uses zero form here.
- 因为他不要离开他的… → 因为不要离开他的…: 他 is already clear in this close continuation, so delete it; Chinese uses zero form here.

**Coherence: temporality (了/着/在)**
- 所以他成为哲学家 → 所以他成为了哲学家: Becoming a philosopher is a completed change in the story, so it takes 了completed.

## shennong_samples#8

### Scene 1

> 古代的时候，有一个人叫神农。一天，神农正在路上走，一看很多人正在吃一些植物。一些人一吃植物就生病了，神农想帮别人。所以想知道哪些植物能吃，哪些植物不能吃。

**Grammar**
- 古代的时候 → 在古代: 古代 is the setting/location for the action, so use 在+Place before the action: 在古代。
- (suggestion) 哪些植物不能吃 → 哪些不能吃: It would be more natural to omit the repeated noun after 哪些: 哪些植物能吃，哪些不能吃。

**Vocabulary**
- 一看很多人正在吃… → 一看到很多人正在吃…: 神农 actually sees this situation, so use 看到see, not 看look.
- (suggestion) 神农想帮别人 → 神农想帮助别人: It would be more natural to use the full verb 帮助 here: 想帮助别人。

### Scene 2

> 然后，神农开始尝很多植物，比方说他吃过生姜、芥兰和菠菜。一些植物吃真好，特别是黄瓜。但是，一些植物毒得很，特别是夹竹桃。

**Grammar**
- 一些植物吃真好 → 一些植物吃起来真好吃: Use 吃起来真好吃 to describe how the plants taste. 吃真好 does not form a natural taste expression here.

**Vocabulary**
- (suggestion) 一些植物毒得很 → 一些植物有毒得很: It would be more natural to say 有毒. Here you need an Adj. to describe the plants, and 有毒 means “poisonous.”
- (suggestion) 一些植物毒得很 → 一些植物毒: It would be more natural to delete 得很 after 毒. Use 有毒 to describe poisonous plants; 毒得很 is not the needed Adj. form here.

### Scene 3

> 一个人对神农说，麻烦我们可以吃什么植物？神农说，这就要看你想不想生病了。以后，神农告诉别人一些植物能吃，一些植物不能吃。

**Grammar**
- (suggestion) 一些植物不能吃 → 一些不能吃: It would be more natural to delete 植物 because it was just mentioned. 一些能吃，一些不能吃 avoids repeating the noun.

**Vocabulary**
- 这就要看你想不想生病… → 这就要看到你想不想生病…: 看 is “look,” while 看到 is “see.” The person actually sees the situation, so use 看到, not 看.

**Coherence: connectors**
- (suggestion) …你想不想生病了 → …你想不想生病: It would be more natural to delete 了 here. 想不想生病 already gives the not definite condition, so 了 is unnecessary.

**Other**
- 麻烦我们可以吃什… → 请问我们可以吃什…: 麻烦 means “trouble,” so it is not a natural polite question opener here. Use 请问 to begin the question politely.

## shennong_samples#19

### Scene 1

> 古代的时候，一个男人觉得植物很有意思。他叫神农。有的植物吃了以后他的肚子疼死了，可是有的吃了以后很舒服。他找很多植物。

**Grammar**
- 古代的时候 → 在古代: 古代 is the setting, so use 在+Place before the action: 在古代。
- (suggestion) 他找很多植物 → 他找了很多植物: It would be more natural to use 了 after 找 because this is a completed action in the narrative: 找了很多植物。
- 他找很多植物 → 他找很多植物了: Use 了 for a completed action in the narrative: 找了很多植物。

**Vocabulary**
- (suggestion) 可是有的吃了以后很舒服 → 可是有的吃了之后很舒服: It would be more natural to use 之后 for the event meaning “after eating”; 以后 is more often used for later or future time.

**Coherence: reference**
- ⟦他⟧叫神农: This character appears for the first time, so please introduce him briefly with an identifying noun phrase, not only 他.

### Scene 2

> 凉山很大的山，这也找植物。一天，他找到黄色的花。他听说你跟黄色的花做茶很有用。比方说，你的头发疼死，这冰茶是药。他一喝茶就很不舒服。

**Grammar**
- 凉山很大的山 → 凉山是一座很大的山: For one mountain, use 是一座 before the description.
- 他找到黄色的花 → 他找到一朵黄色的花: A single flower needs the measure word 朵. Say 一朵黄色的花.
- …跟黄色的花做茶很有用 → …跟黄色的花做的茶很有用: The phrase before 茶 modifies it, so add 的: 做的茶.
- 你的头发疼死 → 你的头发疼死了: Add 了 after 疼死 to show the resulting state.

**Vocabulary**
- 他听说你跟黄色的花做茶… → 他听说用黄色的花做茶…: Use 用 to say “use yellow flowers to make tea.”
- 你的头发疼死 → 你的头疼死: 头发 means “hair.” For a headache, say 头疼.
- (suggestion) 他一喝茶就很不舒服 → 他一喝茶就觉得很不舒服: It would be more natural to say 觉得很不舒服 to describe how he feels after drinking the tea.

**Coherence: reference**
- 这也找植物 → 他也找植物: 这 refers to a thing, but the person looking for plants is Shennong. Use 他.
- 这冰茶是药 → 这种茶是药: 这种茶 means “this kind of tea” and clearly refers to the tea just mentioned.

### Scene 3

> 糟糕，这黄色的花是夹竹桃，特别是毒。正好在这儿，灵芝药的夹竹桃他吃完了，也写一个课文的植物。谢谢神农。

**Grammar**
- 也写一个课文的植物 → 也写一个关于植物的课文: 写 must take the thing being written as its object. Use 关于植物的课文 for “a text about plants.”

**Vocabulary**
- 这黄色的花是夹… → 这朵黄色的花是夹…: 朵 normally collocates with a single flower; use 这朵黄色的花.
- 特别是毒 → 特别有毒: here the structure needs a verb phrase describing the flower. Use 有毒, not 是毒.
- 也写一个课文的植… → 也写了一个课文的植…: Use 了 after 写 because the writing is a completed action in this sequence.

**Content**
- 灵芝药的夹竹… → 有灵芝药的夹竹…: Use 有 after 在这儿 to show that the 灵芝药 is present there. This keeps the story information clear.

## shennong_samples#33

### Scene 1

> 古代时候，人不知道他们能吃什么植物，常常一吃就死。但是不知道为什么，没有办法。所以有一天，神农出去试一试很多种植物，告诉人什么植物是安全什么是危险。

**Grammar**
- 告诉人什么植物是安… → 告诉人们什么植物是安…: Use 人们 when the recipient means people in general.
- …么植物是安全什么是危险 → …么植物是安全的什么是危险: 安全 describes an omitted noun after 是, so use 的: 是安全的.
- …全什么是危险 → …全什么是危险的: 危险 describes an omitted noun after 是, so use 的: 是危险的.

**Vocabulary**
- 神农出去试一试很多种植物 → 神农出去试了很多种植物: 一试 does not naturally collocate with many kinds of plants here. Use 了 to show the past action was completed.

**Coherence: reference**
- 人不知道他们能吃什么植物 → 人不知道自己能吃什么植物: Use 自己 to refer back to the general subject 人, rather than 他们.
- ⟦神农⟧出去试一试很…: 神农 appears for the first time here, so please introduce him briefly, for example as a person who wanted to help people learn about plants.

**Other**
- 古代时候 → 古代: 时候 is redundant because 古代 already expresses the time meaning.

### Scene 2

> 发现有的植物对身体非常好，特别是茶，让肚子感觉又暖和又清楚。他告诉朋友：“你吃哪种植物，这就要看你的口味。比方说，你爱吃甜的，可能喜欢糖。”他最喜欢吃花，除了夹竹桃以外，什么都花想吃。

**Grammar**
- 什么都花想吃 → 什么花都想吃: Put 花 after 什么: 什么花都 means “all kinds of flowers.”

**Vocabulary**
- …感觉又暖和又清楚 → …感觉又暖和又清醒: Use 清醒 for a person who feels awake. 清楚 means clear or understood, so it does not describe this feeling.
- 这就要看你的口味 → 这就要看你的口味: 这里是在说“depends on your taste,” not actually seeing something. Use 看, not 看到.

**Coherence: connectors**
- 可能喜欢糖 → ，这样可以喜欢糖: Use ，这样可以 to show the result or purpose of choosing something sweet: ，这样可以喜欢糖。

**Content**
- 让肚子感觉又暖和又… → 让人感觉又暖和又…: 茶让人感觉暖和、清醒，不是让肚子感觉“清楚”。

### Scene 3

> 他发现这个口味，一百岁时候，不小心吃了毒的花。一吃就开始死。但是生病时候告诉人什么植物是药，什么植物是毒。

**Vocabulary**
- (suggestion) 他发现这个口味 → 他有这个口味: It would be more natural to say 有 because a preference is something a person has; 发现 means to discover something.
- 一百岁时候 → 一百岁的时候: 一百岁的时候 is the established expression for “when [someone was] one hundred years old.”
- 不小心吃了毒的花 → 不小心吃了有毒的花: Here the structure needs an Adj. before 花. 有毒的 means “poisonous,” while 毒的 is not the usual form here.
- (suggestion) 什么植物是毒 → 什么是毒: It would be more natural to omit 植物 here because the plants are already clear from 什么植物是药.
- 什么植物是毒 → 什么植物有毒: Here the structure needs an Adj. form. 有毒 means “poisonous”; 是毒 is not natural for describing a plant.

**Coherence: reference**
- 一吃就开始死 → 一吃就开始死了: Use 了 after 死 to show the death is completed.

**Coherence: connectors**
- 一吃就开始死 → 一吃就死: 一吃就死 is the natural result pattern. Do not use 开始 with 死 here.

**Content**
- 但是生病时候告诉人什… → 但是生病的时候告诉人什…: Use 生病的时候 for this time expression; 的 comes before 时候.
